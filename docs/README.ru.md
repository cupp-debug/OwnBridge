# OwnBridge

**Есть VPS? Поднимите собственный частный VPN.**

OwnBridge — локальный инструмент развёртывания для Android. Нужен лишь VPS с Ubuntu и общедоступным IPv4-адресом: введите данные для входа, выберите протокол и нажмите «Начать развёртывание». OwnBridge настроит сервер, проверит узлы и создаст конфигурации.

По завершении можно запросить URL подписки для **Clash/Mihomo** и получить ссылки на узлы для импорта в **v2rayN/v2rayNG**. Не нужно вводить команды на сервере или писать конфигурационные файлы вручную.

**Ваш сервер. Ваши узлы. От настройки до готовых ссылок — несколько нажатий.**

**[⬇ Скачать APK для Android (arm64-v8a)](https://github.com/cupp-debug/OwnBridge/releases/download/v0.1.1/OwnBridge-v0.1.1-arm64.apk)**

## Текущее состояние

v0.1.1 — выпуск с исправлениями, улучшающий совместимость развёртывания с образами Ubuntu для VPS. OwnBridge не является VPN-провайдером и не предоставляет серверы или учётные записи. APK без режима отладки поддерживает комбинированное развёртывание SS, VLESS Reality и Hysteria 2. Не все сочетания VPS, сети и клиента проверены; о проблемах можно сообщать через GitHub Issues. APK доступен как вложение GitHub Release, а не как файл в репозитории.

## Возможности

- Проверяет ОС, адреса, открытые порты, службы и брандмауэр VPS по SSH без изменения сервера.
- Закрепляет ключ SSH-хоста, проверяет версионированный пакет развёртывания по SHA-256 и записывает ход выполнения на сервере для безопасных повторных попыток.
- Создаёт YAML для Clash/Mihomo и ссылки для v2rayN/v2rayNG на основе подтверждённых результатов. Ссылку подписки Clash можно запросить вручную.
- Проверяет каждый узел HTTP-запросом через Mihomo с устройства Android. Это не ICMP ping и не запуск VPN на Android.
- Сохраняет подтверждённые результаты и журналы в зашифрованной локальной истории. Пароль root от VPS не сохраняется.

## Требования и сборка

- Android 8.0 или новее с поддержкой `arm64-v8a`.
- VPS с Ubuntu 22.04, 24.04 или 26.04 x86_64, которым вы имеете право управлять, и доступом root по SSH. Поддерживаемые сочетания зависят от ограничений текущей сборки.
- JDK 21 и Android SDK API 36 для сборки.

Для локальной разработки выполните `./gradlew.bat :app:assembleDebug` в Windows или `./gradlew :app:assembleDebug` в macOS/Linux. Публичный APK собирается отдельно без режима отладки и подписывается ключом выпуска; см. [руководство по сборке и подписи](BUILDING.md). При сборке загружается мост Mihomo для Android закреплённой версии с проверкой SHA-256. При развёртывании на VPS загружается закреплённая версия sing-box из исходного проекта с проверкой хеша.

## Безопасность

Вводите учётные данные только от VPS, который принадлежит вам или которым вам разрешено управлять. При первом подключении ключ SSH-хоста принимается по принципу доверия при первом использовании; при его изменении соединение останавливается до явной проверки. Конфигурации и ссылки подписки содержат данные доступа к прокси. Сейчас ссылка подписки на VPS использует HTTP, а не HTTPS: получивший ссылку или наблюдающий сетевой трафик может прочитать эти данные. Считайте ссылку секретной и замените затронутые данные доступа при утечке.
