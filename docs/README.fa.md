# OwnBridge

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Türkçe](README.tr.md) · [فارسی](README.fa.md)

**یک VPS دارید؟ VPN شخصی خودتان را راه‌اندازی کنید.**

OwnBridge ابزار استقرار محلی برای اندروید است. کافی است یک VPS با اوبونتو و نشانی IPv4 عمومی داشته باشید: اطلاعات ورود را وارد کنید، پروتکل را انتخاب کنید و «شروع استقرار» را بزنید. OwnBridge نصب روی سرور، بررسی گره‌ها و ساخت پیکربندی را انجام می‌دهد.

پس از پایان، می‌توانید نشانی اشتراک **Clash/Mihomo** را درخواست کنید و پیوندهای گره قابل‌واردکردن در **v2rayN/v2rayNG** را بگیرید. نیازی به اجرای فرمان روی سرور یا نوشتن دستی فایل پیکربندی نیست.

**سرور خودتان. گره‌های خودتان. از نصب تا تحویل، تنها با چند لمس.**

**[⬇ دریافت APK اندروید (arm64-v8a)](https://github.com/cupp-debug/OwnBridge/releases/download/v0.1.1/OwnBridge-v0.1.1-arm64.apk)**

## وضعیت فعلی

v0.1.1 نسخه‌ای با اصلاحات نگهداری است که سازگاری استقرار با ایمیج‌های اوبونتو برای VPS را بهبود می‌دهد. OwnBridge ارائه‌دهندهٔ VPN نیست و سرور یا حساب کاربری در اختیار شما نمی‌گذارد. APK بدون قابلیت اشکال‌زدایی از استقرار ترکیبی SS، VLESS Reality و Hysteria 2 پشتیبانی می‌کند. همهٔ ترکیب‌های سرور، شبکه و برنامهٔ کاربر آزمایش نشده‌اند؛ می‌توانید مشکلات را در GitHub Issues گزارش کنید. APK به‌صورت پیوست GitHub Release عرضه می‌شود و در خود مخزن قرار نمی‌گیرد.

## قابلیت‌ها

- سیستم‌عامل، نشانی‌ها، درگاه‌های باز، سرویس‌ها و وضعیت دیوار آتش VPS را از طریق SSH و بدون تغییر سرور بررسی می‌کند.
- کلید میزبان SSH را ثبت می‌کند، بستهٔ نسخه‌دار استقرار را با SHA-256 می‌سنجد و پیشرفت سمت سرور را برای تلاش دوبارهٔ ایمن نگه می‌دارد.
- از نتایج تأییدشدهٔ استقرار، فایل YAML برای Clash/Mihomo و پیوندهای اشتراک‌گذاری برای v2rayN/v2rayNG می‌سازد. پیوند اشتراک Clash نیز به درخواست کاربر ارائه می‌شود.
- هر گره را با یک درخواست HTTP از طریق Mihomo روی دستگاه اندروید می‌آزماید. این آزمون، ICMP ping نیست و VPN اندروید را فعال نمی‌کند.
- نتایج تأییدشده و گزارش‌ها را در تاریخچهٔ محلیِ رمزگذاری‌شده ذخیره می‌کند. گذرواژهٔ root سرور ذخیره نمی‌شود.

## پیش‌نیازها و ساخت

- دستگاهی با Android 8.0 یا جدیدتر و پشتیبانی از `arm64-v8a`.
- VPS با Ubuntu 22.04، 24.04 یا 26.04 x86_64 که مجاز به مدیریت آن هستید و دسترسی root از راه SSH دارد. ترکیب‌های پشتیبانی‌شده به محدودیت‌های نسخهٔ فعلی وابسته‌اند.
- JDK 21 و Android SDK API 36 برای ساخت برنامه.

برای توسعهٔ محلی، در Windows دستور `./gradlew.bat :app:assembleDebug` و در macOS یا Linux دستور `./gradlew :app:assembleDebug` را اجرا کنید. APK عمومی جداگانه و بدون امکان اشکال‌زدایی ساخته و با کلید انتشار امضا می‌شود؛ [راهنمای ساخت و امضا](BUILDING.md) را ببینید. هنگام ساخت، پل اندروید Mihomo با نسخهٔ ثابت دریافت و مقدار SHA-256 آن بررسی می‌شود. هنگام استقرار روی VPS نیز نسخهٔ ثابت sing-box از پروژهٔ اصلی دریافت و هش آن بررسی می‌شود.

## امنیت

فقط اطلاعات ورود VPS متعلق به خودتان یا سروری را وارد کنید که مجوز مدیریت آن را دارید. کلید میزبان SSH در نخستین اتصال بر پایهٔ «اعتماد در اولین استفاده» ثبت می‌شود؛ اگر تغییر کند، اتصال تا بررسی صریح شما متوقف می‌شود. فایل‌های پیکربندی و پیوندهای اشتراک حاوی اطلاعات دسترسی پروکسی هستند. پیوند اشتراک میزبانی‌شده روی VPS در حال حاضر از HTTP، نه HTTPS، استفاده می‌کند؛ هر کس پیوند را به دست آورد یا بتواند ترافیک را ببیند ممکن است این اطلاعات را بخواند. پیوند را محرمانه نگه دارید و در صورت افشا، اطلاعات دسترسی مربوط را تغییر دهید.
